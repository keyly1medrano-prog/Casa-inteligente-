 Casa inteligente controlada por una red web

Una casa inteligente controlada por una red web es un proyecto tecnológico que permite controlar y supervisar diferentes dispositivos de una vivienda mediante una página web conectada a un sistema electrónico. Su funcionamiento se basa en la programación, la robótica y el uso de sensores que permiten automatizar distintas tareas del hogar.

¿Cómo funciona?

El sistema utiliza una página web como interfaz para enviar instrucciones y visualizar información. La tarjeta Arduino procesa las instrucciones y recibe los datos de los sensores para controlar los componentes electrónicos conectados.

Componentes del sistema y sus funciones

- Cables de conexión: permiten unir los diferentes componentes electrónicos.
- Cable USB para la tarjeta Arduino: sirve para conectar la tarjeta a una computadora y cargar el programa.
- LEDs: representan luces que pueden encenderse y apagarse mediante la programación.
- Resistencias: regulan el paso de corriente para proteger los componentes.
- Tarjeta Arduino: es el componente principal que procesa las instrucciones y controla los dispositivos.
- Dos protoboards mini: permiten conectar los componentes sin necesidad de soldarlos.
- Sensor analógico: mide una variable física y envía una señal que Arduino puede interpretar.
- Sensor de movimiento o sensor PIR: detecta el movimiento de personas u objetos que emiten radiación infrarroja.
- Sensor de infrarrojos: permite detectar objetos o señales mediante luz infrarroja.
- Sensor de humedad: mide la humedad del ambiente o del suelo, según el tipo de sensor.
- Matriz de LEDs de 8 × 8: permite mostrar símbolos, letras, números o pequeños mensajes.
- Módulo relé de un canal: permite controlar el encendido y apagado de un dispositivo eléctrico compatible.
- Pantalla OLED monocromática: muestra información del sistema, como lecturas de sensores y estados de funcionamiento.
- Sensor de huella digital: permite identificar una huella registrada para implementar un sistema de acceso.
- Sensor de distancia ultrasónico: mide la distancia entre el sensor y un objeto mediante ondas ultrasónicas.
- Display de 7 segmentos: muestra números para representar valores o resultados.
- Una pantalla: permite visualizar información adicional del sistema, dependiendo de su tipo y conexión.
- Microservomotor: permite realizar movimientos controlados, como abrir o cerrar una pequeña puerta de maqueta.

Objetivo del proyecto

El objetivo es integrar la programación, la electrónica y las redes web para desarrollar una vivienda automatizada a pequeña escala. Con estos componentes se pueden representar funciones como la iluminación automática, la detección de movimiento, la medición de humedad, el control de acceso y la visualización de datos.

 Conclusión

Este proyecto demuestra cómo la tecnología puede facilitar el control de diferentes funciones de una vivienda. Mediante Arduino, los sensores, las pantallas y una interfaz web, es posible crear un sistema inteligente que contribuya a la automatización, la comodidad y la seguridad del hogar.
