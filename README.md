 Casa inteligente controlada por una red web
1. Descripción del proyecto

Una casa inteligente controlada por una red web es un proyecto tecnológico que permite controlar y supervisar diferentes dispositivos de una vivienda mediante una página web conectada a un sistema electrónico. Su funcionamiento se basa en la programación, la robótica y el uso de sensores que permiten automatizar distintas tareas del hogar.

 2. Objetivo general

Integrar la programación, la electrónica y las redes web para desarrollar una vivienda automatizada a pequeña escala mediante Arduino, sensores y dispositivos electrónicos.

3. ¿Cómo funciona?

El sistema utiliza una página web como interfaz para enviar instrucciones y visualizar información. La tarjeta Arduino procesa las instrucciones programadas y recibe los datos de los sensores para controlar los componentes electrónicos conectados.

De esta manera, se pueden representar funciones como el control de iluminación, la detección de movimiento, la medición de temperatura y la apertura automática de una puerta.

 4. Componentes del sistema y sus funciones

- **Cables de conexión:** permiten unir los diferentes componentes electrónicos.
- **Cable USB para Arduino:** conecta la tarjeta a una computadora y permite cargar el programa.
- **LEDs:** representan luces que pueden encenderse y apagarse mediante la programación.
- **Resistencias:** regulan el paso de corriente para proteger los componentes.
- **Tarjeta Arduino:** procesa las instrucciones y controla los dispositivos conectados.
- **Dos protoboards mini:** permiten conectar los componentes sin necesidad de soldarlos.
- **Sensor analógico:** mide una variable física y envía una señal que Arduino puede interpretar.
- **Sensor de movimiento PIR:** detecta movimiento mediante cambios en la radiación infrarroja.
- **Sensor de infrarrojos:** permite detectar objetos o señales mediante luz infrarroja.
- **Sensor de humedad:** mide la humedad ambiental o del suelo, según el tipo de sensor.
- **Matriz de LEDs de 8 × 8:** permite mostrar símbolos, letras, números y mensajes cortos.
- **Módulo relé de un canal:** permite controlar dispositivos eléctricos compatibles.
- **Pantalla OLED monocromática:** muestra lecturas de sensores y estados del sistema.
- **Sensor de huella digital:** identifica huellas registradas para implementar un sistema de acceso.
- **Sensor ultrasónico de distancia:** mide la distancia entre el sensor y un objeto.
- **Display de 7 segmentos:** muestra números para representar valores o resultados.
- **Pantalla adicional:** permite visualizar información complementaria del sistema, según su tipo y conexión.
- **Microservomotor:** realiza movimientos controlados, como abrir o cerrar una puerta de maqueta.

 5. Pasos para desarrollar el proyecto

Paso 1. Investigación

Recopilar información sobre las casas inteligentes, la automatización del hogar, la robótica, Arduino y las redes web.

 Paso 2. Planificación y diseño

Definir los objetivos del proyecto, seleccionar los componentes electrónicos y diseñar la estructura de la maqueta.

 Paso 3. Construcción de la maqueta

Preparar la estructura de la casa utilizando los materiales seleccionados para representar una vivienda automatizada.

 Paso 4. Ensamblaje del circuito electrónico

Conectar la tarjeta Arduino, los sensores, los LEDs, la pantalla y los demás componentes necesarios para representar las funciones del sistema.

 Paso 5. Programación del sistema

Desarrollar el código para procesar las lecturas de los sensores y controlar los dispositivos electrónicos.

Paso 6. Simulación del circuito

Utilizar Tinkercad para diseñar y simular el circuito electrónico, comprobar las conexiones y verificar el funcionamiento del programa.

Paso 7. Desarrollo de la página web

Crear una interfaz web para presentar la información del proyecto, explicar sus funciones y organizar los documentos, las imágenes y los videos relacionados.

 Paso 8. Integración y pruebas

Revisar las conexiones, comprobar el funcionamiento de los componentes y realizar las correcciones necesarias en el circuito y el código.

 Paso 9. Documentación y presentación

Organizar los trabajos F-1, F-2, F-3, F-4 y F-5, preparar las evidencias del proyecto y presentar el funcionamiento de la casa inteligente.

 6. Funciones del sistema

- **Iluminación:** permite representar el encendido y apagado de luces mediante programación y sensores.
- **Detección de movimiento:** identifica movimiento mediante un sensor PIR.
- **Medición de temperatura:** permite leer y visualizar datos de temperatura.
- **Control de acceso:** representa un sistema de identificación mediante huella digital.
- **Apertura automática:** permite controlar el movimiento de una puerta de maqueta mediante un microservomotor.
- **Visualización de datos:** presenta información en pantallas y displays.

Nota: las funciones disponibles dependen de los componentes instalados, las conexiones y el programa utilizado.
